# 待合室デジタルサイネージ v6

横浜駅前ながしまクリニックの待合室ディスプレイ用スライドショーです。

## これは何か

`index.html` を1つ開くだけで動く、待合室のテレビ・モニター用のスライドショー画面です。
インターネット接続は不要です（外部のCDN・フォント・画像を一切使っていません）。院内の待合室モニターに繋いだPC/タブレットで `index.html` をブラウザで開き、そのままフルスクリーン表示にしてください（多くのブラウザは `F11` でフルスクリーンになります）。

内科・産婦人科の診療時間、内視鏡実績、担当医師の専門医資格、胃カメラ/大腸カメラ（受診の流れ含む）・日帰りポリープ切除・人間ドック・横浜市の検診・予防接種/健診・自費診療・土曜診療・アクセス・医療ブログなどの案内、胸やけ・胃の不調・ピロリ菌・便秘や下痢・便の変化・貧血・痔・AI内視鏡診断支援・更年期・ピル外来・健診結果放置・生活習慣病・発熱外来・マイナ保険証・女性への配慮といった症状別・診療方針の受診案内、大腸カメラを3枚連続で深掘りする特集シリーズ、季節のお知らせ（梅雨、熱中症、食中毒、夏バテ、秋の健診、秋の花粉、インフルエンザ、花粉症、感染性胃腸炎、年末年始、冬の乾燥対策、新年度の健康チェックなど）、WEB予約案内（QRコード付き）、マスク着用のお願い、を自動で順番に切り替えて表示します。画面下のフッターには院名・最寄り駅からの案内・現在の日時（秒まで動く時計）が常に表示されます。

一部の重要なスライド（院名紹介・診療時間・内視鏡実績・WEB予約）は、1周の中で2回表示されるよう設定しています（詳しくは「表示頻度（weight）について」を参照）。

季節（春夏秋冬）によって背景の色味や飾りが自動で変わり、季節限定のお知らせ（熱中症・インフル・花粉症など）もその時期だけ自動で表示されます。手動での切り替え作業は不要です。

診療時間外（夜19:00〜翌朝7:30、設定変更可）は自動で「本日の診療は終了しました」という夜間画面に切り替わります。日曜だけは夜間画面にはせず、通常のスライドショーの上に「本日は休診日です」という帯を表示します（祝日は自動判定していません。次項参照）。

## スライドの文言・表示月を変える方法

`index.html` をテキストエディタ（メモ帳や VS Code など）で開き、`<script>` タグの中にある `SLIDES` という配列を探してください（ファイル内を「SLIDES」で検索すると見つかります）。

スライドは1つずつ、以下のような形になっています。

```js
{
  id: "heatstroke",           // スライドの識別名（英数字）
  months: [6, 7, 8, 9],       // 表示する月。1〜12の数字の配列、または "all"（年中表示）
  duration: 11,               // 表示時間（秒）
  render: () => `
    <div class="kicker">季節のお知らせ</div>
    <div class="headline small">熱中症にご注意ください</div>
    <div class="point-list">
      <div class="point"><span class="dot"></span>こまめな水分補給を心がけましょう</div>
      ...
    </div>
  `
}
```

- **文言を変える**：`render:` の中の日本語テキストを書き換えるだけです（`<div>` などのタグはそのまま残してください）。
- **表示する月を変える**：`months: [6, 7, 8, 9]` の数字を増減させます。年中表示したい場合は `months: "all"` にします。
- **表示時間を変える**：`duration: 11` の数字（秒）を変えます。
- **スライドを増やす／減らす**：`{ ... }` の1ブロックをまるごとコピーして新しいスライドを作れます。削除する場合はブロックごと消してください（ブロックの間の `,`（カンマ）の付け忘れ・消し忘れに注意してください）。
- **表示順を変える**：`SLIDES` 配列の中でブロックの並び順を入れ替えるだけです。

保存後、ブラウザで `index.html` を開き直す（またはF5で再読み込み）と反映されます。

## 表示頻度（weight）について

特に見てほしいスライドは、1周の中で複数回表示させることができます。スライドのブロックに `weight: 2` を追加すると、そのスライドは1周に2回登場します（書かない場合は通常どおり1回＝`weight: 1` 扱いです）。

```js
{
  id: "welcome",
  months: "all",
  duration: 12,
  weight: 2,   // 1周に2回表示する
  render: () => `...`
}
```

現在は `welcome`（院名紹介）・`hours`（内科診療時間）・`endoscopy-count`（内視鏡実績）・`web-yoyaku`（WEB予約）の4枚に `weight: 2` を設定しています。2回目は同じスライドが連続しないよう、自動的に1周のちょうど反対側あたりに差し込まれる仕組みになっています（並び順を手作業で調整する必要はありません）。画面下の進行ドットも、重複を含めた実際の周回数ぶん表示されます。

`weight` を消せば1回表示に戻り、`weight: 3` のように増やすことも可能です（1周が長くなりすぎない範囲でご利用ください）。

## 特集シリーズ（連続スライド）について

1つのテーマを複数枚に分けてじっくり伝えたいときは、「特集シリーズ」の形が使えます。現在は `tokushu-colono-1` → `tokushu-colono-2` → `tokushu-colono-3` の3枚が「大腸カメラ特集」として `SLIDES` 配列内で連続配置されており、画面右上に「大腸カメラ特集 1/3」のようなシリーズバッジが表示されます。

新しい特集シリーズを作りたいときは、各スライドの `render:` の中に次の1行を追加し、`SLIDES` 配列の中でそのスライドたちを連続して並べてください（間に他のスライドを挟まないこと）。

```js
render: () => `
  <div class="series-badge">○○特集 1/3</div>
  <div class="kicker">...</div>
  ...
`
```

バッジの文言（「○○特集 1/3」の部分）はそのままテキストとして表示されるので、番号や総数はテーマに合わせて書き換えてください。

## 実績数値（内視鏡件数など）の月次更新のやり方

同じく `<script>` タグの中、`SLIDES` より上にある `CLINIC` というオブジェクトの中の `endoscopy` の部分を探してください（「endoscopy」で検索）。

```js
endoscopy: {
  asOf: "2026年7月時点",       // 基準時点の表示文言
  totalLabel: "開院からの累計",
  total: 2013,                 // 累計件数（特大数字で表示）
  gastroTotal: 1012,           // 胃カメラ累計
  colonoTotal: 1001,           // 大腸カメラ累計
  monthLabel: "2026年7月の実績",
  monthTotal: 177,             // 当月合計
  monthGastro: 90,             // 当月・胃カメラ
  monthColono: 87              // 当月・大腸カメラ
}
```

数字を最新の値に書き換えるだけで、「内視鏡実績」スライドの表示（累計2,013件、など）が自動で更新されます。カンマ区切り表記は自動で付くので、数字はカンマなしで入力してください（例：`2013` であって `"2,013"` ではありません）。

診療時間（内科・産婦人科）や電話番号、診療科名なども同じ `CLINIC` オブジェクトの中にまとまっています。`hoursNaika` / `hoursGyn` の `am` / `pm` に `true`（○）/ `false`（×）を並べると診療時間表の○×が変わります。

## 夜間画面・休診日の帯について

診療時間外は自動で夜間画面（院名・大きな時計・「本日の診療は終了しました」）に切り替わります。切り替わる時刻は `index.html` のいちばん上のほう、`NIGHT_MODE` というところで変更できます（「NIGHT_MODE」で検索）。

```js
const NIGHT_MODE = {
  startHour: 19,   // この時刻から夜間画面になる
  startMinute: 0,
  endHour: 7,      // この時刻に夜間画面が終わり、通常表示に戻る
  endMinute: 30
};
```

- 日曜日だけは夜間画面にはならず、通常のスライドショーの上部に「本日は休診日です」という帯を表示します。
- **祝日は自動判定していません。** オフラインで祝日を正確に判定する方法がないためです。祝日は通常どおり平日扱いのスライドショーになりますので、祝日の休診は必要に応じて「臨時お知らせ」枠（次項）を使ってください。
- 境界の時刻をまたぐと、1分以内に自動で画面が切り替わります（再読み込み不要）。

## WEB予約QRコードの更新方法

「WEB予約が便利です」のスライドに表示しているQRコードは、`index.html` 内の `QR_YOYAKU` という定数に画像データとして埋め込まれています（「QR_YOYAKU」で検索）。外部と通信しない仕組みのため、QRコード画像そのものをファイルの中に持っています。

予約システムの予約ページURLが変わった場合は、新しいURLでQRコード画像（PNG）を作り直し、その画像を data URI（`data:image/png;base64,...` という形式の文字列）に変換して、`QR_YOYAKU` の中身をまるごと差し替える必要があります。QRコード画像の作成・data URI化は開発チームにご依頼ください。

## 臨時お知らせの出し方

臨時休診など、一時的なお知らせを出したいときは、専用の枠を使うと簡単です。`index.html` 内を「NOTICE」で検索すると、以下のような場所が見つかります（`SLIDES` より少し上にあります）。

```js
const NOTICE = {
  enabled: false,             // true にすると画面に表示されます
  title: "臨時休診のお知らせ",  // 見出し
  lines: [                    // 本文（1行ずつ）。増減もできます
    "○月○日（○）は都合により休診とさせていただきます",
    "ご不便をおかけし、誠に申し訳ございません"
  ]
};
```

使い方:
1. `title` と `lines` を実際のお知らせ内容に書き換える
2. `enabled: false` を `enabled: true` に変える
3. 保存して、ブラウザで `index.html` を開き直す（またはF5で再読み込み）

これでスライドの中に「お知らせ」画面が挟まるようになります。お知らせが不要になったら `enabled` を `false` に戻すだけで、他のスライドに影響なく非表示にできます。

## 検証用URLパラメータ

普段は何も付けずに `index.html` を開けば、今日の月・現在時刻で正しく動作します。以下は動作確認のためのオプションです。

| パラメータ | 例 | 内容 |
|---|---|---|
| `?month=10` | `index.html?month=10` | 10月として表示（季節テーマ・季節限定スライドの絞り込みに反映されます。実機の日付は変わりません） |
| `?speed=2` | `index.html?speed=2` | スライドの切り替え時間を1/2に短縮（動作確認を早く回すためのオプション） |
| `?slide=hours` | `index.html?slide=hours` | 指定した `id` のスライドから表示を開始します |
| `?hour=22` | `index.html?hour=22` | 「今が22時である」ことにして夜間画面の切り替わりを確認できます（0〜23の整数のみ。小数不可）。分・秒は実際の時刻のままです |
| `?dow=0` | `index.html?dow=0` | 「今日は日曜日である」ことにして休診日の帯を確認できます（0=日曜〜6=土曜、`Date.getDay()`と同じ並び） |

組み合わせて使うこともできます（例：`index.html?month=12&speed=4`、`index.html?dow=0&hour=22` で「日曜の夜」を再現して、夜間画面にならないことを確認する、など）。

## その他の自動動作

- 日付が変わると自動で画面を再読み込みします（1時間おきにチェック）。日付をまたいだまま古い日時表示が残ることはありません。
- 3秒間マウス操作がないと、マウスカーソルは自動で非表示になります。
- 万一スライドの描画でエラーが起きても、ローテーション全体は止まらないようにしています。
- スライドの背景には、丸ドット・ゆるい波・斜めの色面の3種類の控えめな装飾がスライドごとに順番に切り替わります（表示内容には影響しません）。
- 画面に表示される時計（フッター・夜間画面とも）は実際の現在時刻です。検証用の `?hour=` は夜間画面に切り替わるかどうかの判定だけを偽装するもので、表示される時計の数字までは変わりません。
