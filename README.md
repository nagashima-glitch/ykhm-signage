# 待合室デジタルサイネージ v26

横浜駅前ながしまクリニックの待合室ディスプレイ用スライドショーです。

## これは何か

`index.html` を1つ開くだけで動く、待合室のテレビ・モニター用のスライドショー画面です。
インターネット接続は不要です（外部のCDN・フォント・画像を一切使っていません）。院内の待合室モニターに繋いだPC/タブレットで `index.html` をブラウザで開き、そのままフルスクリーン表示にしてください（多くのブラウザは `F11` でフルスクリーンになります）。

内科・産婦人科の診療時間、内視鏡実績、担当医師の専門医資格・AI内視鏡診断支援・人間ドック・横浜市の検診・予防接種/健診・自費診療・土曜診療・アクセス・医療ブログなどの院内案内、療養計画書・健診結果放置・マイナ保険証・医療DX・院内感染対策・お薬（ジェネリック/リフィル処方箋）・女性への配慮・スタッフへの迷惑行為お断りといった診療方針・院内制度の案内、季節のお知らせ（梅雨、熱中症、食中毒、夏バテ、秋の健診、秋の花粉、インフルエンザ、花粉症、感染性胃腸炎、年末年始、冬の乾燥対策、新年度の健康チェックなど）、WEB予約案内（QRコード付き）、マスク着用のお願いに加えて、**「こんな症状ありませんか？→章扉→◯◯とは→章扉→検査の目的→章扉→検査の流れ（1シーン1ステップ）→検査の注意点→まとめ・CTA」という流れで1テーマを深掘りする「特集シリーズ」**（大腸カメラ・胃カメラ・便潜血・生活習慣病・おなかの不調・機能性ディスペプシア（FD）・からだからのサイン・痔のお悩み・ピル・更年期・子宮頸がん検診・女性のからだ相談・生理痛・PMS・経血量が多い方へ・逆流性食道炎・ピロリ菌・人間ドック・貧血の19シリーズ、計118枚）と、季節限定の熱中症・インフルエンザ・感染性胃腸炎・花粉症・かぜ・発熱ミニ番組を自動で順番に切り替えて表示します。画面下のフッターには院名・最寄り駅からの案内・現在の日時（秒まで動く時計）が常に表示されます。

一部の重要なスライド（院名紹介・診療時間・内視鏡実績・WEB予約）は、1周の中で2回表示されるよう設定しています（詳しくは「表示頻度（weight）について」を参照）。

季節（春夏秋冬）によって背景の色味や飾りが自動で変わり、季節限定のお知らせ（熱中症・インフル・花粉症など）もその時期だけ自動で表示されます。手動での切り替え作業は不要です。

診療時間外（夜19:00〜翌朝7:30、設定変更可）は自動で「本日の診療は終了しました」という夜間画面に切り替わります。日曜だけは夜間画面にはせず、通常のスライドショーの上に「本日は休診日です」という帯を表示します（祝日は自動判定していません。次項参照）。

一部のスライドは、左にテキスト・右にイラスト（角丸カード＋薄い影）を並べた「画像つきレイアウト」で表示されます。使っているイラストはすべて `images/` フォルダ内のファイルで、外部通信は発生しません（詳しくは「画像つきスライドについて」を参照）。

一部のスライド（特集シリーズの多くと、WEB予約・内視鏡実績・生活習慣病特集など）は、深緑・ローズ・紺・季節色などのベタ塗り背景に白文字の「ポスター調」レイアウトで表示され、単調にならないようアクセントになっています（詳しくは「デザインテーマ（bold/light）について」を参照）。さらに院名紹介や各特集シリーズの1枚目、熱中症・インフルエンザ・マイナ保険証・健診結果放置・スタッフへの迷惑行為お断りなどは、専用のイラスト背景いっぱいに写真調ポスターを敷き、空いたスペースに文字を載せる「フルポスターレイアウト」です（詳しくは「フルポスタースライドについて」を参照）。見出しや本文の重要語には、マーカー風（通常時）または白帯ボックス風（ポスター調・フルポスタースライド時）の強調がついています。文字のフォントは「Zen Kaku Gothic New」です（詳しくは「フォントについて」を参照）。

## 先生用：全スライドを一覧で確認する方法（preview.html）

**「今どんなスライドがあるか見たい」ときは、`index.html` ではなく `preview.html` を開いてください。**

`preview.html` をブラウザで開くと、季節限定のスライドや普段は表示されない「臨時お知らせ」も含めて、**全スライドをサムネイル一覧**で確認できます。

- 「通年スライド」「季節限定スライド」「特集シリーズ」「院内・制度のご案内」「臨時お知らせ（通常は非表示）」の5つに分類されています
- サムネイルをクリックすると、その場で拡大表示されます（別タブは開きません）
- スマートフォンやタブレットでも開けます
- ページの一番上に本番画面（`index.html`）へのリンクもあります

`preview.html` はあくまで確認用のページで、待合室では表示しません。実際の放映は `index.html` が行います。

## ファイル構成

```
digital-signage/
├── index.html    ← 待合室で実際に流す本番画面（これを開いて放映する）
├── preview.html  ← 先生用：全スライドを一覧確認するページ（放映はしない）
├── slides.js     ← スライドの中身・院の情報など「データ」はすべてここにある
├── images/       ← 画像つきスライドで使うイラスト（16:9のJPEG、53枚）
├── photos/       ← 院内実写真（16:9のJPEG、10枚）
├── posters/      ← フルポスタースライドで使う背景画像（16:9のJPEG、10枚）
├── fonts/        ← 見出し・本文フォント「Zen Kaku Gothic New」（woff2×4・OFLライセンス）
└── README.md     ← このファイル
```

**スライドの中身を編集するときは、`index.html` ではなく `slides.js` を開いてください。** `index.html` にはローテーションや夜間モードなどの「動かす仕組み」だけが入っており、`slides.js` の内容を `index.html` と `preview.html` の両方が読み込んでいます（同じデータを2箇所に書かなくてよいように、1つのファイルにまとめてあります）。

## スライドの文言・表示月を変える方法

`slides.js` をテキストエディタ（メモ帳や VS Code など）で開き、`SLIDES` という配列を探してください（ファイル内を「SLIDES」で検索すると見つかります）。

スライドは1つずつ、以下のような形になっています。

```js
{
  id: "necchusho-series-2",    // スライドの識別名（英数字）
  title: "熱中症ミニ番組 2/3（水分と塩分）", // preview.html の一覧に出す短いタイトル
  category: "seasonal",       // preview.html での分類（下記参照）
  months: [6, 7, 8, 9],       // 表示する月。1〜12の数字の配列、または "all"（年中表示）
  duration: 10,               // 表示時間（秒）
  render: () => `
    <div class="kicker">熱中症ミニ番組</div>
    <div class="headline small">まずは、涼しい場所で水分と塩分を</div>
    <div class="point-list">
      <div class="point"><span class="dot"></span>こまめな水分補給と、涼しい環境が第一です</div>
      ...
    </div>
  `
}
```

- **文言を変える**：`render:` の中の日本語テキストを書き換えるだけです（`<div>` などのタグはそのまま残してください）。
- **表示する月を変える**：`months: [6, 7, 8, 9]` の数字を増減させます。年中表示したい場合は `months: "all"` にします。
- **表示時間を変える**：`duration: 11` の数字（秒）を変えます。
- **スライドを増やす／減らす**：`{ ... }` の1ブロックをまるごとコピーして新しいスライドを作れます。削除する場合はブロックごと消してください（ブロックの間の `,`（カンマ）の付け忘れ・消し忘れに注意してください）。新しく作ったスライドには `title`（一覧用の短い名前）と `category`（`"all"` / `"seasonal"` / `"series"` / `"institutional"` / `"notice"` のいずれか）も付けてください。付け忘れても本番画面（`index.html`）は問題なく動きますが、`preview.html` の一覧に正しく出なくなります。
- **表示順を変える**：`SLIDES` 配列の中でブロックの並び順を入れ替えるだけです。

保存後、ブラウザで `index.html`（本番）または `preview.html`（一覧）を開き直す（またはF5で再読み込み）と反映されます。

## 画像つきスライドについて

`images/` フォルダには、待合室のイラスト画像が16:9のJPEGで53枚入っています。すべてこのフォルダの中の画像を `<img src="images/xx.jpg">` の形で読み込んでいるだけなので、外部通信は発生しません。

`photos/` フォルダには、院内の実写真が16:9のJPEGで10枚入っています。実写真も `<img src="photos/xx.jpg">` または `poster: "photos/xx.jpg"` の形で読み込み、外部通信は発生しません。写真を全面背景にするスライドでは、自動で暗めのグラデーションを敷いて白文字の可読性を保ちます。

スライドのブロックに `image:` を追加すると、そのスライドは自動的に「左にテキスト（55%）・右にイラスト（45%、角丸カード＋薄い影）」の2カラムレイアウトになります（`render:` の中身はいつもどおり書くだけで、画像の配置は `index.html` 側が自動で行います）。

```js
{
  id: "gastro",
  months: "all",
  duration: 12,
  image: "images/gastro.jpg",   // このイラストが右側に表示される
  render: () => `...`
}
```

- **画像なしのスライドに戻す**：`image:` の行を消すだけで、これまでどおりの中央寄せレイアウトに戻ります。
- **画像とテキストの左右を入れ替える**：`imageReverse: true` を追加すると、その1枚だけ画像が左・テキストが右になります。同じ画像を使うスライドが連続するときの単調さを避けるために使っています（例：`tounyou`）。
- 画像は既存の53枚から選んで使うことを想定しています。新しいイラストを追加したい場合は、16:9のJPEGを `images/` に置き、開発チームにファイル名を伝えてください。

## 疾患解説カード（diseaseCard）について（v15〜）

「症状のある方への案内」スライド（各特集シリーズ内の「リスク」「ピロリ菌」などのスライド）は、`render:` の中で生の `<div>` を書く代わりに `diseaseCard({...})` という共通の書き方を使っています。**こんな症状ありませんか？→健診で異常ありませんか？→放置するとこんなリスクが→当院でこんな治療ができます**、という訴求の流れを毎回同じ見た目で作れるようにするためのものです。

```js
{
  id: "hinketsu-series-2",
  months: "all",
  duration: 11,
  render: () => diseaseCard({
    kicker: "貧血ミニ特集",                       // 画面左上のラベル（変更なし）
    headline: "貧血の陰に、出血がかくれていることも", // 見出し（質問形が基本）
    rows: [
      { label: "確認を", text: "胃や大腸からの出血が原因のことがあります" },
      { label: "おすすめ", text: "特に男性の貧血は、一度検査での確認をおすすめします", emphasis: true }
    ],
    cta: "健診で指摘された方は、お早めに"         // 細い罫線の下に出る、結びの1行
  })
}
```

- `rows` は1行〜4行など可変です（症状／健診で／放置すると／当院でできること、など内容に応じて増減できます）。特集シリーズの「リスク」だけのスライドのように、`rows` が1行だけの場合もあります。
- `label` には「こんな症状」「健診で」「放置すると」「我慢すると」「当院でできること」のように、その行が何を伝えているかを短く書きます。
- `emphasis: true` を付けた行だけ、タグの背景が塗りつぶされて目立ちます（「放置すると」等、リスクを伝える行に使うと効果的です）。付けない行は枠線だけの控えめな見た目のままです。同じラベル（例：「放置すると」）を1枚の中で2回使うこともできます。
- `headline` は省略できます（キー自体を書かなければ、見出しなしで `kicker` と `rows` だけのスライドになります。「検査の流れ」のようにステップだけを見せたいスライドで使います）。
- `cta` は省略できます（キー自体を書かなければ、結びの1行は表示されません）。特集シリーズの中間スライドのように、あえてCTAを出さない構成にも使えます。
- `<em>タグ</em>` は各スライド1箇所（1〜2語）だけ使うのが基本です。使いすぎると強調の意味が薄れます。
- **医療広告ガイドラインの注意**：`rows` や `cta` の文言は、断定的な効果表現（「治ります」等）・数値・料金・比較の最上級表現を避け、「〜があります」「〜を目指します」といった表現にとどめてください。迷ったら開発チーム（コーディネーター）に確認してから反映してください。
- `image:`（右側にイラスト）を付けたスライドでも、`diseaseCard(...)` の戻り値がそのままテキスト側に収まるので、書き方は変わりません。

### 番号ステップ行（`{ step, text }`）について（v18〜）

「検査の流れ」のように手順を順番に見せたいときは、`rows` の各行を `label` の代わりに `step`（数字）で書くと、タグの代わりに**丸数字バッジ**（tone色の丸＋白い数字）になります。

```js
render: () => diseaseCard({
  kicker: "検査の流れ",
  rows: [
    { step: 1, text: "検査前の飲食はお控えいただきます" },
    { step: 2, text: "経鼻・経口、鎮静剤の使用をお選びいただけます" },
    { step: 3, text: "観察後はリカバリールームで休憩し、ご帰宅です" }
  ]
})
```

- `step` には好きな数字を渡せます。手順が2枚に分かれるとき（大腸カメラ特集の①②のあと③④⑤に続く、など）は、2枚目の `step` を `3, 4, 5` のように続きの数字にしてください（自動連番ではありません）。
- 1つの `rows` の中で `label` 行と `step` 行を混在させることもできますが、見た目を揃えるため通常はどちらかに統一してください。

## 章扉スライド（`chapterSlide`）とビルドアップアニメについて（v18〜）

特集シリーズの中で「大腸カメラとは」「検査の目的」「検査の流れ」のように、話の区切りだけを見せる5秒間の“章扉”を挟めるようになりました。参考にしたのは他社の疾患解説動画にある「タイトル→章扉→定義→章扉→目的→章扉→流れ→注意点→まとめ」という構成です。

```js
{
  id: "colono-series-2",
  title: "大腸カメラ特集 2/13（章扉：大腸カメラとは）",
  category: "series",
  months: "all",
  duration: 5,          // 章扉は5秒固定が基本
  theme: "bold",
  tone: "green",
  centered: true,       // 中央揃えレイアウトにする（側面の縦書きラベルも出さない）
  render: () => chapterSlide("大腸カメラ特集", "大腸カメラとは")
}
```

- `chapterSlide(seriesLabel, title)` は、`seriesLabel`（画面左上の小さなラベル）と `title`（中央に特大表示される章タイトル）を渡すだけのヘルパーです。タイトル下に丸角の下線が入り、v14からのエディトリアル調デザインと統一しています。
- 章扉スライドには背後のゴースト数字（`seriesBadge`）は付けません（呼び出さないだけでOKです）。
- `centered: true` を付けると、診療時間表などと同じ「中央揃えレイアウト」（`.slide-centered`）になり、画面右端の縦書きラベルも出なくなります。章扉以外のスライドでも、中央に寄せたい単発スライドがあれば同じように使えます。

**ビルドアップアニメ**：`diseaseCard(...)` の各行（`.dc-row`）と `point-list` の各項目（`.point`）は、スライドが画面に表示された（activeになった）タイミングで、上から順に0.4秒間隔でフェードインします。書き方は今までどおりで、`index.html` 側が自動でアニメーションを付けるため `slides.js` の編集は不要です。OSの「視差効果を減らす」設定（`prefers-reduced-motion: reduce`）が有効な環境では、アニメーションなしで最初から表示された状態になります。



## デザインテーマ（bold/light）について

スライドのブロックに `theme: "bold"` と `tone: "○○"` を追加すると、そのスライドだけ「ベタ塗り背景＋白文字」のポスター調デザインになります（何も指定しなければ、これまでどおりのクリーム色背景＝`light`）。

```js
{
  id: "necchusho-series-2",
  months: [6, 7, 8, 9],
  duration: 11,
  theme: "bold",   // ベタ塗り背景にする
  tone: "summer",  // 背景色の系統（下記参照）
  render: () => `...`
}
```

`tone` は次の5種類があり、それぞれ決まった配色になります（配色そのものは `index.html` 側で管理しているため、`tone` を指定するだけでOKです）。

| tone | 系統 | 使用例 |
|---|---|---|
| `green` | 消化器・内視鏡系（深緑） | 内視鏡実績、大腸カメラ特集、胃カメラ特集、おなかの不調特集、痔のお悩み特集 |
| `rose` | 婦人科系（落ち着いたローズ） | 更年期特集、ピル特集 |
| `navy` | 制度・院内（紺） | 院名紹介、WEB予約、便潜血特集、生活習慣病特集、スタッフへの迷惑行為お断り |
| `summer` | 季節（夏・深い青緑） | 熱中症 |
| `autumn` | 季節（秋・橙茶） | インフルエンザ特集 |
| `spring` | 季節（春・桜色） | 花粉症特集 |
| `winter` | 季節（冬・藍） | 感染性胃腸炎特集 |

- **現在ベタ塗り背景（`theme:"bold"`）にしているのは68枚**（各特集シリーズの多くのスライド・内視鏡実績・WEB予約）です。各シリーズの1枚目・院名紹介・熱中症・インフルエンザ特集・マイナ保険証・健診結果放置・スタッフへの迷惑行為お断りなどは、後述の「フルポスターレイアウト」に切り替えています。1つのシリーズ内は同じtone（色系統）で統一し、「続き物」として見えるようにしています。
- **ボールドをやめて元のクリーム背景に戻す**：`theme:` の行を削除するだけです（`tone:` は強調ボックスの色にも使われるので残してOK）。
- ボールドスライドのQRコードカードには白いフチ（ステッカー風の縁取り）が自動でつきます。QRコードの白背景・サイズは変わりません（スキャンのしやすさを保つためです）。

## フルポスタースライドについて

スライドのブロックに `poster: "posters/poster_xx.jpg"` または `poster: "photos/photo_xx.jpg"` と `posterTextSide: "left"|"right"` を追加すると、そのスライドは背景いっぱいにポスター画像・実写真を敷き、画像の空いているスペース側に白文字でテキストを載せる「フルポスターレイアウト」になります。

```js
{
  id: "necchusho-series-1",
  months: [6, 7, 8, 9],
  duration: 11,
  tone: "summer",                          // 強調ボックスの文字色に使う
  poster: "posters/poster_heatstroke.jpg", // 背景いっぱいに敷く画像

```

- `posters/` フォルダには先生からいただいたポスター画像（16:9のJPEG）が10枚、`photos/` フォルダには院内実写真（16:9のJPEG）が10枚入っています。イラストや写真の見せたい要素と文字が重ならないよう、**必ず空きスペース側に `posterTextSide` を合わせてください**（逆にすると文字が重なって読みにくくなります）。
- 文字の後ろにはうっすら暗いグラデーション（同系色の帯）が自動で敷かれ、白文字の可読性を保ちます。
- 背景画像はスライド表示中に20秒かけてごくゆっくり拡大する演出（scale 1.0→1.06）が入ります。診療時間・実績・QRコードなど、既存の落ち着いたレイアウトのスライドには使っていません。

- WEB予約スライドは対応するポスター画像が無いため、これまでどおりQR付きのベタ塗り背景（`theme:"bold"`）のままにしています。

## フォントについて

見出し・本文には「Zen Kaku Gothic New」というフォントを使っています（`fonts/` フォルダに軽量化済みのファイルが入っています）。見出し＝Black（900）・kicker/ラベル＝Bold（700）・本文＝Medium（500）の3ウェイトを使い分けています。

- **ライセンス**：Google Fontsで配布されているオープンソースフォントで、SIL Open Font License 1.1（無料・商用利用可）です。ライセンス全文は `fonts/OFL.txt` にあります。
- **文字を絞り込んだ「サブセット」フォントです**：ファイルを軽くするため、今のスライドの文言で実際に使っている文字だけを抜き出しています（`fonts/subset_chars.txt` に一覧があります）。
- **サブセットに無い文字が出てきたら**：そのままでもエラーにはなりません。フォントにその文字の形が無いときは、ブラウザが自動的に次点の「ヒラギノ角ゴ」に切り替えて表示するので、見た目の崩れはありません。ただし1つの単語の中でZen Kaku Gothic Newの文字とヒラギノの文字が混ざり、フォントの太さが微妙に変わって見えることがあります。
- **新しい漢字を文言に追加したとき**：もしその漢字がサブセットに入っていなければ、その文字だけヒラギノ表示になります。気になる場合は、サブセットフォントの作り直し（新しい文字を追加して再書き出し）が必要なので、**開発チーム（コーディネーター）にご依頼ください**。先生ご自身でファイルを直す必要はありません。

## キーワード強調（`<em>`）について

見出しや本文の中で特に読んでほしい語句は、`<em>語句</em>` のように囲むと自動で強調表示されます。

```js
<div class="headline small"><em>マイナ保険証</em>をご用意ください</div>
```

- **通常のスライド（light）**：落ち着いた金茶色のマーカーを引いたような下線ハイライトになります。
- **ポスター調・フルポスターのスライド（bold / poster）**：白い帯（ボックス）にテーマ色の文字が水平に乗る、シール風の強調になります。
- 文言そのものは変わらないので、医療広告ガイドライン上の表現ルールには影響しません。**強調するのは1スライドにつき1箇所（1〜2語）まで**にとどめてください（つけすぎると効果が薄れます）。

## 装飾モチーフについて

各スライドの右下には、ごく薄い円弧が1本だけ自動配置されます（`index.html` 側で自動生成しており、`slides.js` の編集は不要です）。色はスライドのテーマに合わせて自動で変わります（通常スライドは控えめな配色、ポスター調・ベタ塗りスライドは白の半透明）。季節限定スライド（`category: "seasonal"`）は、既存の季節の飾り（画面全体に漂う丸いモチーフ）を優先し、この円弧は重ねて表示しません。

## 表示頻度（weight）について

特に見てほしいスライドは、1周の中で複数回表示させることができます。スライドのブロックに `weight: 2` を追加すると、そのスライドは1周に2回登場します（書かない場合は通常どおり1回＝`weight: 1` 扱いです）。

```js
{
  id: "welcome",
  months: "all",
  duration: 12,
  weight: 2,   // 1周に2回表示する
  render: () => `...`
}
```

現在は `welcome`（院名紹介）・`hours`（内科診療時間）・`endoscopy-count`（内視鏡実績）・`web-yoyaku`（WEB予約）の4枚に `weight: 2` を設定しています。2回目は同じスライドが連続しないよう、自動的に1周のちょうど反対側あたりに差し込まれる仕組みになっています（並び順を手作業で調整する必要はありません）。画面下の進行ドットも、重複を含めた実際の周回数ぶん表示されます。

`weight` を消せば1回表示に戻り、`weight: 3` のように増やすことも可能です（1周が長くなりすぎない範囲でご利用ください）。

## 実績数値（内視鏡件数など）の月次更新のやり方

同じく `slides.js` の中、`SLIDES` より上にある `CLINIC` というオブジェクトの中の `endoscopy` の部分を探してください（「endoscopy」で検索）。

```js
endoscopy: {
  asOf: "2026年7月時点",       // 基準時点の表示文言
  totalLabel: "開院からの累計",
  total: 2013,                 // 累計件数（特大数字で表示）
  gastroTotal: 1012,           // 胃カメラ累計
  colonoTotal: 1001,           // 大腸カメラ累計
  monthLabel: "2026年7月の実績",
  monthTotal: 177,             // 当月合計
  monthGastro: 90,             // 当月・胃カメラ
  monthColono: 87              // 当月・大腸カメラ
}
```

数字を最新の値に書き換えるだけで、「内視鏡実績」スライドの表示（累計2,013件、など）が自動で更新されます。カンマ区切り表記は自動で付くので、数字はカンマなしで入力してください（例：`2013` であって `"2,013"` ではありません）。

診療時間（内科・産婦人科）や電話番号、診療科名なども同じ `CLINIC` オブジェクトの中にまとまっています。`hoursNaika` / `hoursGyn` の `am` / `pm` に `true`（○）/ `false`（×）を並べると診療時間表の○×が変わります。

## 夜間画面・休診日の帯について

診療時間外は自動で夜間画面（院名・大きな時計・「本日の診療は終了しました」）に切り替わります。切り替わる時刻は `slides.js` のいちばん上のほう、`NIGHT_MODE` というところで変更できます（「NIGHT_MODE」で検索）。

```js
const NIGHT_MODE = {
  startHour: 19,   // この時刻から夜間画面になる
  startMinute: 0,
  endHour: 7,      // この時刻に夜間画面が終わり、通常表示に戻る
  endMinute: 30
};
```

- 日曜日だけは夜間画面にはならず、通常のスライドショーの上部に「本日は休診日です」という帯を表示します。
- **祝日は自動判定していません。** オフラインで祝日を正確に判定する方法がないためです。祝日は通常どおり平日扱いのスライドショーになりますので、祝日の休診は必要に応じて「臨時お知らせ」枠（次項）を使ってください。
- 境界の時刻をまたぐと、1分以内に自動で画面が切り替わります（再読み込み不要）。

## WEB予約QRコードの更新方法

「WEB予約が便利です」のスライドに表示しているQRコードは、`slides.js` 内の `QR_YOYAKU` という定数に画像データとして埋め込まれています（「QR_YOYAKU」で検索）。外部と通信しない仕組みのため、QRコード画像そのものをファイルの中に持っています。

予約システムの予約ページURLが変わった場合は、新しいURLでQRコード画像（PNG）を作り直し、その画像を data URI（`data:image/png;base64,...` という形式の文字列）に変換して、`QR_YOYAKU` の中身をまるごと差し替える必要があります。QRコード画像の作成・data URI化は開発チームにご依頼ください。

## 臨時お知らせの出し方

臨時休診など、一時的なお知らせを出したいときは、専用の枠を使うと簡単です。`slides.js` 内を「NOTICE」で検索すると、以下のような場所が見つかります（`SLIDES` より少し上にあります）。

なお `preview.html` の「臨時お知らせ」欄は、`enabled` の値に関わらず常に内容を確認できます（先生が中身をチェックしやすいようにするためです。本番の `index.html` は `enabled: true` のときだけ表示します）。

```js
const NOTICE = {
  enabled: false,             // true にすると画面に表示されます
  title: "臨時休診のお知らせ",  // 見出し
  lines: [                    // 本文（1行ずつ）。増減もできます
    "○月○日（○）は都合により休診とさせていただきます",
    "ご不便をおかけし、誠に申し訳ございません"
  ]
};
```

使い方:
1. `title` と `lines` を実際のお知らせ内容に書き換える
2. `enabled: false` を `enabled: true` に変える
3. 保存して、ブラウザで `index.html` を開き直す（またはF5で再読み込み）

これでスライドの中に「お知らせ」画面が挟まるようになります。お知らせが不要になったら `enabled` を `false` に戻すだけで、他のスライドに影響なく非表示にできます。

## 検証用URLパラメータ

普段は何も付けずに `index.html` を開けば、今日の月・現在時刻で正しく動作します。以下は動作確認のためのオプションです。

| パラメータ | 例 | 内容 |
|---|---|---|
| `?month=10` | `index.html?month=10` | 10月として表示（季節テーマ・季節限定スライドの絞り込みに反映されます。実機の日付は変わりません） |
| `?speed=2` | `index.html?speed=2` | スライドの切り替え時間を1/2に短縮（動作確認を早く回すためのオプション） |
| `?slide=hours` | `index.html?slide=hours` | 指定した `id` のスライドから表示を開始します |
| `?hour=22` | `index.html?hour=22` | 「今が22時である」ことにして夜間画面の切り替わりを確認できます（0〜23の整数のみ。小数不可）。分・秒は実際の時刻のままです |
| `?dow=0` | `index.html?dow=0` | 「今日は日曜日である」ことにして休診日の帯を確認できます（0=日曜〜6=土曜、`Date.getDay()`と同じ並び） |
| `?freeze=1` | `index.html?slide=hours&freeze=1` | 指定したスライドを表示したままローテーションを止めます（`preview.html` の拡大表示で使われています） |
| `?forcenotice=1` | `index.html?slide=notice&forcenotice=1` | `NOTICE.enabled` が `false` でも、`notice` スライドの中身を確認できます（`preview.html` 専用の確認用） |

組み合わせて使うこともできます（例：`index.html?month=12&speed=4`、`index.html?dow=0&hour=22` で「日曜の夜」を再現して、夜間画面にならないことを確認する、など）。

## その他の自動動作

- 日付が変わると自動で画面を再読み込みします（1時間おきにチェック）。日付をまたいだまま古い日時表示が残ることはありません。
- 3秒間マウス操作がないと、マウスカーソルは自動で非表示になります。
- 万一スライドの描画でエラーが起きても、ローテーション全体は止まらないようにしています。
- スライドの背景には、丸ドット・ゆるい波・斜めの色面の3種類の控えめな装飾がスライドごとに順番に切り替わります（表示内容には影響しません）。
- 画面に表示される時計（フッター・夜間画面とも）は実際の現在時刻です。検証用の `?hour=` は夜間画面に切り替わるかどうかの判定だけを偽装するもので、表示される時計の数字までは変わりません。
